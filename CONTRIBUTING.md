# Contributing

Use Python 3.12 through 3.14 and install `.[test]`. Changes must preserve the
five-Catalog registry, mapping-first Evidence Expressions, deployment ownership
of Collector/Adapter/Engine configuration, and the one-distribution repository
boundary. Run every command in the README development section before opening a
pull request. New public interfaces require contract fixtures and migration notes.
